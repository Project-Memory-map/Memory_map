# app/modules/memories/ui/

Giao diện module ký ức, phục vụ ở `/memories/...`. HTML của panel "Của tôi", "Chuyến đi" và form ký ức nằm trong `app/shared/ui/map.html`, nên thư mục này chỉ có CSS.

| File | Công dụng |
|---|---|
| `memories.css` | CSS panel "Của tôi", panel "Chuyến đi", thẻ ký ức, form tạo/sửa ký ức, ô chọn ảnh/video, chi tiết ký ức trong ngăn kéo |

> Khi thêm, sửa hoặc xóa file trong thư mục này, nhớ cập nhật bảng trên.
