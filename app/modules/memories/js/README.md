# app/modules/memories/js/

Xử lý phía trình duyệt của module ký ức, phục vụ ở `/memories/js/...`. Dùng ở `map.html`.

| File | Công dụng |
|---|---|
| `memories.js` | `Memories`: ghim xanh của tôi, danh sách + bộ lọc thời gian, chi tiết ký ức, form tạo/sửa (ảnh, video, hashtag, gợi ý hashtag), đổi riêng tư/công khai, xóa |
| `trips.js` | `Trips`: danh sách chuyến đi, tạo/sửa/xóa, thêm/bỏ ký ức, vẽ lộ trình theo thời gian trên bản đồ |

> Khi thêm, sửa hoặc xóa file trong thư mục này, nhớ cập nhật bảng trên.
