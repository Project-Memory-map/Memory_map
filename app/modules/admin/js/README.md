# app/modules/admin/js/

Xử lý phía trình duyệt của trang quản trị, phục vụ ở `/admin/js/...`.

| File | Công dụng |
|---|---|
| `admin.js` | Kiểm tra quyền admin, tải thống kê, tìm ký ức/tài khoản, ẩn/bỏ ẩn/xóa ký ức và khóa/mở khóa tài khoản (bắt buộc nhập lý do), xem nhật ký |

> Khi thêm, sửa hoặc xóa file trong thư mục này, nhớ cập nhật bảng trên.
