# app/modules/admin/ui/

Giao diện trang quản trị, phục vụ ở `/admin/`.

| File | Công dụng |
|---|---|
| `index.html` | Trang quản trị `/admin/`: thống kê, tìm và ẩn/xóa ký ức, tìm và khóa tài khoản, nhật ký thao tác |
| `admin.css` | CSS riêng trang quản trị |

> Khi thêm, sửa hoặc xóa file trong thư mục này, nhớ cập nhật bảng trên.
