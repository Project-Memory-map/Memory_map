# app/modules/explore/ui/

Giao diện module khám phá, phục vụ ở `/explore/...`. HTML của panel "Khám phá" nằm trong `app/shared/ui/map.html`, nên thư mục này chỉ có CSS.

| File | Công dụng |
|---|---|
| `explore.css` | CSS panel "Khám phá": bộ lọc, chip hashtag, danh sách kết quả |

> Khi thêm, sửa hoặc xóa file trong thư mục này, nhớ cập nhật bảng trên.
