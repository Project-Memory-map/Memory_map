# app/shared/ui/

Giao diện dùng chung, chỉ gồm HTML + CSS. Phục vụ ở đường dẫn gốc `/`.

| File | Công dụng |
|---|---|
| `index.html` | Trang mở đầu (`/`): giới thiệu, 3 bước sử dụng, ký ức cộng đồng mới nhất, giới thiệu nhóm |
| `map.html` | Trang chủ bản đồ (`/ban-do`): thanh trên, bản đồ, thanh bên gồm panel **Khám phá** (M3), **Của tôi** và **Chuyến đi** (M2), cùng mẫu form tạo/sửa ký ức `<template id="memory-form-template">` |

| Thư mục | Công dụng |
|---|---|
| [`css/`](css/README.md) | CSS dùng chung và CSS của 2 trang trên |
| [`img/`](img/README.md) | Ảnh, biểu tượng |

> Khi thêm, sửa hoặc xóa file trong thư mục này, nhớ cập nhật bảng trên.
