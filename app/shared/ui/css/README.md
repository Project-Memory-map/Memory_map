# app/shared/ui/css/

CSS dùng chung, phục vụ ở `/css/...`.

| File | Công dụng |
|---|---|
| `base.css` | Hệ thống giao diện chung cho **mọi trang**: biến màu, font, nút, ô nhập, thẻ, hộp thoại, thông báo (toast) |
| `landing.css` | Riêng trang mở đầu (`index.html`) |
| `map.css` | Riêng trang bản đồ (`map.html`): thanh trên, ô tìm địa điểm, ghim, lớp bản đồ, popup, ngăn kéo |

> Khi thêm, sửa hoặc xóa file trong thư mục này, nhớ cập nhật bảng trên.
