# app/shared/

Phần dùng chung giữa các trang, tách 2 phần: **giao diện** (`ui/`) và **xử lý** (`js/`).

| Thư mục | Công dụng |
|---|---|
| [`ui/`](ui/README.md) | Giao diện: trang mở đầu, trang chủ bản đồ, CSS chung, ảnh |
| [`js/`](js/README.md) | Xử lý phía trình duyệt dùng chung: gọi API, tiện ích giao diện, bản đồ Leaflet |

> Khi thêm, sửa hoặc xóa file trong thư mục này, nhớ cập nhật bảng trên.
