# scripts/

Các script chạy tay bằng dòng lệnh (`python scripts/<tên>.py`).

| File | Công dụng |
|---|---|
| `init_db.py` | ⚠️ *Chưa có nội dung* – tạo database bằng cách chạy `database/schema.sql` + `seed_regions.sql` từ Python (thay cho Workbench). Hiện mỗi thành viên chạy bằng Workbench nên chưa cần |
| `seed_demo.py` | ⚠️ *Chưa có nội dung* – tạo dữ liệu mẫu (tài khoản, ký ức, chuyến đi) để thử giao diện. Thành viên M1 + M2 bổ sung khi đã có API đăng ký và tạo ký ức |

> ⚠️ Thư mục này chưa có file nào có nội dung. Thành viên làm chức năng có dùng đến thư mục này phải **bổ sung mô tả từng file vào README này**.

> Khi thêm, sửa hoặc xóa file trong thư mục này, nhớ cập nhật bảng trên.
